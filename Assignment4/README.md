# Assignment 4: GAN-Based Fraud Detection

This assignment uses GAN-based anomaly detection for credit card fraud detection. Fraud is rare in the dataset, so the models focus on learning normal transaction behavior and identifying unusual transactions.

## Open First

Start with:

```text
Team_36.ipynb
```

This is the recommended final notebook for review.
