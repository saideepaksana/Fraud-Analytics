# Assignment 2: Spectral Clustering

This assignment uses spectral clustering to find groups of related nodes in a graph. It is an unsupervised task, so the goal is to discover clusters from the graph structure rather than predict existing labels.

## Open First

Start with:

```text
spectralCustering.ipynb
```

This notebook explains the graph construction, Laplacian matrix, eigenvector step, clustering process, and final cluster labels.

| File | Description |
