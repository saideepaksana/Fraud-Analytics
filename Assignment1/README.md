# Assignment 1: Graph Neural Networks

This assignment uses graph neural networks for node classification. The data contains nodes, edges, node features, and labels. The task is to learn from both the feature values and the graph connections.

## Open First

Start with:

```text
GNN.ipynb
```

This is the main notebook for understanding the workflow.

## Files

| File | Description |
|---|---|
| `GNN.ipynb` | Main graph neural network notebook. |
| `graph_classification.ipynb` | Additional notebook comparing graph model variants. |
| `features.csv` | Feature values for each node. |
| `edges.csv` | Graph connections between nodes. |
| `labels.csv` | Target labels for node classification. |
| `report.pdf` | Final assignment report. |
| `FraudAssgn1.zip` | Submitted archive. |
